# 智场通V1.0管理端任务

## 概述：

简洁易懂 目前有羽毛球馆和网球场地

管理员打开小程序 → 进入管理端看到场馆列表 → 点「编辑」修改开放时间 → 系统弹出变更预览（将新增X个时段、删除X个时段、已有人预约保留X个）→ 确认后时段重建写入数据库。管理员预约与普通用户相同：浏览场馆 → 选时间段 → 系统弹出可选场地（普通时段灰/绿同用户端，紫色为「管理员专属」普通用户不可见）→ 确认下单 → 提交成功写入数据库。普通用户不开放的时间段（开馆前/闭馆后），管理员同样可见并可直接预约；开放时段已满时，管理员可「转为内部预留」或「调大容量」获得优先权，系统不允许直接超卖。

## 页面清单（8 个界面）

| 编号 | 界面名 | 用户要完成的事 | 关键元素 |
| --- | --- | --- | --- |
| P1 | 管理端工作台 | 判断今天要做什么：预约、核销还是管理场馆 | 数据概览卡、扫码核销入口、管理员预约入口、场馆管理入口、结算中心入口 |
| P2 | 场馆列表管理 | 找到目标场馆，看运营状态 | 搜索框、新增场馆按钮、场馆卡片（封面/名称/开放时间/今日预约数/今日收益）、上架/下架、临时闭馆、编辑、删除 |
| P3 | 编辑场馆信息 | 更改场地开放时间段等信息 | 表单（名称/分类/价格/容量/地址/封面）、时间选择器（picker 开始-结束）、实时校验提示（结束须晚于开始、间隔≥1小时）、预览变更按钮 |
| P4 | 变更预览确认 | 知道改了时间会有什么后果，最后把关 | 变更对比（原时间→新时间）、将新增时段数、将删除时段数、已有人预约保留数及说明、「再想想」「确认变更」按钮 |
| P5 | 管理员预约·场馆时段 | 像普通用户一样挑时间和场地 | 复用用户端场馆列表/详情/时段矩阵、日期切换、普通时段（绿可约/灰不可约）、紫色「管理员专属」时段、余量与价格、下一步 |
| P6 | 优先权操作弹窗 | 满员时段也能约到 | 满员提示（10/10）、「转为内部预留」「调大容量」「取消」三个选项、二次确认说明（转预留后普通用户立即不可约） |
| P7 | 下单支付 | 和普通用户相同的下单流程 | 订单摘要卡（馆名/时段/价格）、模拟支付、内部订单角标（source=ADMIN） |
| P8 | 时段管理矩阵 | 管理未来每一天的时段：预留、释放、扩容 | 日期切换、时段行（⚪开放/🟣管理员专属/⚔超营业保留/🔴闭馆）、每行操作按钮（预约/预留/释放/扩容）、图例说明 |

## 规则说明

- 管理员预约与普通用户共用同一套页面和接口，权限由后端角色（JWT）自动放行，不单独开发一套预约流程。
- 「管理员专属」时段 = 营业时间外前后各一段（如 07:00-08:00、22:00-23:00），普通用户端完全不显示；普通用户直接调接口预约该时段返回 403。
- 防超卖是硬底线：管理员也不能让已约人数超过物理容量；优先权只能通过「专属时段」「转预留」「调大容量」实现。
- 已有用户预约的时段，管理员修改开放时间后不删除，标记为「超营业保留」直至当日结束。
- 更改开放时间采用两步提交：先预览变更 → 再确认执行，避免手滑破坏 7 天时段。
